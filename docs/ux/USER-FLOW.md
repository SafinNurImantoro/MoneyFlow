# User Flow

## First Use

Register -> Verify/Sign in -> Onboarding -> Add first account -> Dashboard

## Expense

Home -> + -> Expense -> Amount -> Category -> Account -> Date -> Optional Note/Receipt -> Save -> Success -> Dashboard refresh

## Income

Home -> + -> Income -> Amount -> Category -> Account -> Date -> Optional Note -> Save

## Transfer

Home -> + -> Transfer -> Source -> Destination -> Amount -> Save -> Atomic operation -> Success

## Goal

Goals -> New Goal -> Name -> Type -> Target -> Date -> Create -> Goal detail -> Add contribution

## Budget

Budgets -> New Budget -> Category -> Amount -> Period -> Create

## Report

Reports -> Select period -> View summary -> Export PDF
