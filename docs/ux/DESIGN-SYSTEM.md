# Design System

## Direction

Minimal, modern, friendly, trustworthy, mobile-first.

Inspired by the usability principles of the EasyPay reference, not copied.

## Navigation

Mobile: bottom navigation + floating quick action.
Desktop: sidebar.

## Accessibility

- semantic HTML
- visible focus
- labels for form fields
- keyboard support
- sufficient contrast
- minimum touch target approximately 44px
- meaningful aria-labels

## UX Rule

The main action should be obvious without visual clutter.
