# Coding Standards

- TypeScript strict.
- No any unless justified and isolated.
- Prefer explicit domain types.
- Validate all external input.
- No business rules inside presentational components.
- No direct service-role access from browser.
- Use descriptive function names.
- Avoid giant files.
- Keep database queries close to their feature boundary.
- Prefer server components for read-heavy pages.
- Use client components only for interactivity.
- Keep accessibility requirements in component design.
- Add tests for business rules and regressions.
