# User Stories

## Auth
- As a user, I can create an account.
- As a user, I can sign in and sign out.
- As a user, I can recover access.

## Accounts
- As a user, I can create a money account.
- As a user, I can archive an account without losing history.
- As a user, I can see account balance.

## Transactions
- As a user, I can add an expense.
- As a user, I can add income.
- As a user, I can edit a transaction.
- As a user, I can delete a transaction.
- As a user, I can search and filter transactions.

## Transfers
- As a user, I can move money between my accounts.
- As a user, I can see transfers without treating them as spending.

## Budgets
- As a user, I can set a category budget.
- As a user, I can see budget usage and status.

## Goals
- As a user, I can create a savings/purchase target.
- As a user, I can record goal contributions.
- As a user, I can see progress.

## Reports
- As a user, I can view monthly financial summaries.
- As a user, I can export a PDF report.

## Receipts
- As a user, I can attach a receipt image.
- As a user, I can access only my own receipts.
